# CV typography

COSS's default `@coss/style` preset uses Inter for body and heading text:
https://coss.com/ui/docs/get-started

The CV uses Inter Regular (400) and Bold (700), with the neutral default palette:
https://coss.com/ui/docs/styling

The static TTF files were instantiated at optical size 14 from Google's Inter
variable font, preserving the family name and Unicode coverage:
https://github.com/google/fonts/blob/main/ofl/inter/Inter%5Bopsz%2Cwght%5D.ttf

The accompanying SIL Open Font License permits embedding. The font files are
loaded locally for HTML/PDF export and embedded in the PDF and DOCX outputs.
No Google Fonts request is needed to generate or read the CV.
